# GoldMandu Android (target APK &lt; 2 MB)

Two-screen Kotlin app: **Home** (rates only) + **History** (90-day chart).
No Compose, Material, OkHttp, Retrofit, Room, or WorkManager —
those libraries alone push a release APK past 2 MB.

UI mockup: [`design/preview.html`](design/preview.html).

## Size strategy

| Choice | Why |
|--------|-----|
| Views + AppCompat only | Material/Compose cost 1–4 MB |
| `HttpURLConnection` + `org.json` | Platform APIs, zero deps |
| `AlarmManager` daily alarm | WorkManager ~150 KB+ avoided |
| Canvas sparkline | No chart library |
| Vector drawables only | No PNG density buckets |
| R8 full mode + `shrinkResources` | Default in release |
| No Kotlin coroutines dependency | Plain `Thread` + `runOnUiThread` |

Expected release APK: **~1.0–1.6 MB** (verify with `./gradlew :app:assembleRelease`).

## Design language (matches the site)

- Paper `#FFFFFF` / ink `#111111` / muted `#555555` / accent `#6B5A1E`
- Day mode + night mode (`values-night`)
- Square corners, 2 px masthead rule, serif display numerals
- NPR grouping `3,01,800`
- Colored day delta (↑ green / ↓ red)

## API (already generated in this repo)

```
GET https://goldmandu.chandanshakya.com.np/api/latest.json   # ~400 B
GET https://goldmandu.chandanshakya.com.np/api/history.json  # ~5 KB, 90 pts
```

Regenerated by `scripts/sync-api.mjs` from `data/prices.json` (site build + Actions).

## Build

1. Open `android/` in **Android Studio** (Ladybug+ / AGP 8.7).
2. Let Studio create `local.properties` with `sdk.dir=...`.
3. Sync Gradle, then:

```bash
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Debug for development:

```bash
./gradlew :app:installDebug
```

## GitHub Releases (CI)

Workflow: [`.github/workflows/android-release.yml`](../.github/workflows/android-release.yml)

| Trigger | Version |
|---------|---------|
| Push to `main` touching `android/**` | auto `1.0.<run_number>` |
| Tag `v1.2.3` | `1.2.3` / code `10203` |
| Manual dispatch | optional version, else auto |

### One-time: add signing secrets

Open `android/signing/GITHUB_SECRETS.txt` (local only, gitignored) and paste
each NAME/VALUE into **GitHub → Settings → Secrets and variables → Actions**
→ **New repository secret**:

| Secret |
|--------|
| `KEYSTORE_BASE64` |
| `KEYSTORE_PASSWORD` |
| `KEY_ALIAS` |
| `KEY_PASSWORD` |

Keystore: `android/signing/release.p12` (PKCS12). **Back this file up** —
losing it means users cannot update the installed app in place.

Then every push that touches the Android app publishes a signed APK to Releases.

## Notifications

- Toggle in the app → schedules exact alarm at **02:55 UTC** (08:50 NPT).
- Fetches `/api/latest.json`, posts a local notification once per new BS date.
- Reschedules on boot / app update.
- API 33+: requests `POST_NOTIFICATIONS` on first enable.

OEM battery managers (Xiaomi/OPPO/Vivo) can still delay exact alarms. If users
report late alerts, add a battery-optimization prompt or FCM as a follow-up.
